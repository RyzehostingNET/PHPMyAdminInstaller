# 🗄️ Automated phpMyAdmin Installer for Linux

A streamlined installation script to deploy and secure **phpMyAdmin** on Ubuntu/Debian servers with Apache or Nginx and MariaDB/MySQL.

[![Platform](https://img.shields.io/badge/Platform-Ubuntu%20%7C%20Debian-E95420)](https://ubuntu.com)
[![Database](https://img.shields.io/badge/Database-MySQL%20%7C%20MariaDB-00758F)](https://mariadb.org)
[![Host](https://img.shields.io/badge/Maintained%20by-Ryzehosting-6254fe)](https://ryzehosting.com)

---

## ✨ Features
- ⚡ Installs the latest stable phpMyAdmin release.
- 🔒 Secures installation directory with proper file permissions.
- 📦 Configures necessary PHP extensions (`php-mbstring`, `php-zip`, `php-gd`).

---

## 📥 Quick Start (One-Liner)

```bash
curl -sSL https://raw.githubusercontent.com/RyzehostingNET/PHPMyAdminInstaller/main/install.sh | bash
```
